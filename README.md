# Telegram-бот для салона маникюра 💅

Готовый каркас Telegram-бота записи клиентов в салон красоты на Python, aiogram 3.x, SQLAlchemy и SQLite.

## Возможности

- приветствие и красивое главное меню;
- FSM-сценарий записи: услуга → мастер → дата → время → имя → телефон → комментарий → подтверждение;
- проверка занятых, заблокированных и прошедших слотов;
- уведомления администратору о новой/отменённой записи и новом отзыве;
- разделы «Портфолио», «Услуги и цены», «Мои записи», «Контакты», «Отзывы»;
- Telegram-админ-панель по `ADMIN_IDS`;
- структура APScheduler для напоминаний за 24 часа и за 2 часа;
- демо-данные: услуги, мастера, слоты на ближайшие 2 недели и заглушки портфолио.

## Структура

```text
bot/
  config/       # настройки .env
  database/     # SQLAlchemy-модели, сессия, инициализация БД
  handlers/     # пользовательские и админские обработчики
  keyboards/    # inline-клавиатуры
  services/     # бизнес-логика записей и напоминаний
```

## Быстрый старт

1. Создайте бота в Telegram:
   - откройте [@BotFather](https://t.me/BotFather);
   - отправьте `/newbot`;
   - задайте имя и username;
   - скопируйте выданный token.

2. Узнайте свой `admin_id`:
   - напишите [@userinfobot](https://t.me/userinfobot) или аналогичному боту;
   - скопируйте числовой Telegram user_id.

3. Установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

4. Создайте `.env`:

```bash
cp .env.example .env
```

5. Заполните `.env`:

```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=123456789
DATABASE_URL=sqlite+aiosqlite:///./nail_salon.db
```

Несколько администраторов указываются через запятую: `ADMIN_IDS=111,222,333`.

6. Запустите бота:

```bash
python -m bot.main
```

При первом запуске создаются таблицы `users`, `services`, `masters`, `appointments`, `available_slots`, `portfolio`, `reviews` и добавляются демо-данные.

## Админ-панель

Администратор видит кнопку «⚙️ Админ-панель» в главном меню. Доступны:

- просмотр всех записей;
- записи на сегодня;
- поиск записей по дате;
- добавление услуг;
- добавление мастеров;
- добавление рабочих слотов;
- добавление фото/URL в портфолио;
- просмотр отзывов;
- ручная отмена записи.


## Форматы админ-ввода

- Услуга: `Название | описание | цена | длительность_мин`
- Мастер: `Имя | описание`
- Слот: `master_id | ДД.ММ.ГГГГ | ЧЧ:ММ`
- Портфолио: `Категория | file_id или URL | подпись`

## PostgreSQL

Для PostgreSQL установите async-драйвер и измените `DATABASE_URL`:

```bash
pip install asyncpg
```

```env
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/nail_salon
```

## Напоминания

Планировщик подключается в `bot/main.py` через `setup_scheduler(bot)`. Задача раз в минуту ищет активные записи и отправляет сообщения за 24 часа и за 2 часа до визита. Отключить можно в `.env`:

```env
REMINDERS_ENABLED=false
```

## Расширение

Проект разделён на слои: обработчики, клавиатуры, БД и сервисы. Для продакшена рекомендуется добавить миграции Alembic, более строгую валидацию телефона, логирование и полноценные CRUD-экраны для админа.
